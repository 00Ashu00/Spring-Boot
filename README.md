# Spring Boot Learning Repository

A collection of my hands-on learning and practice while exploring Java backend development with Spring Boot.

## Topics Covered

- Spring Boot fundamentals
- REST API development
- CRUD operations
- Spring Data JPA and Hibernate
- PostgreSQL database integration
- Entity relationships
- DTOs and request validation
- Global exception handling
- Pagination
- Layered architecture: Controller, Service, Repository

## Projects

### Hospital Management System

A REST API-based hospital management application built using Spring Boot and PostgreSQL.

**Features**
- Doctor, patient, and appointment management
- CRUD operations for appointments
- Entity relationships between doctors, patients, and appointments
- Request validation and meaningful error responses
- Global exception handling
- Pagination for appointment retrieval
- Appropriate HTTP status codes for API responses

**Tech Stack:** Java, Spring Boot, Spring Data JPA, Hibernate, PostgreSQL, Maven
